# Fieldset Blade component

> Filament 5.x documentation
> Source: https://filamentphp.com/docs/5.x/components/fieldset.md

## Introduction

You can use a fieldset to group multiple form fields together, optionally with a label:

```blade
<x-filament::fieldset>
    <x-slot name="label">
        Address
    </x-slot>

    {{-- Form fields --}}
</x-filament::fieldset>
```
