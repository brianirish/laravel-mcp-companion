# Overview

> Filament 5.x documentation
> Source: https://filamentphp.com/docs/5.x/components/overview.md

## Introduction

Filament packages consume a set of core components that aim to provide a consistent and maintainable foundation for all interfaces. Some of these components are also available for use in your own applications and Filament plugins.

## Package components

The various packages in the Filament project can be used outside of a panel:

- [Action](https://filamentphp.com/docs/5.x/components/action.md)
- [Form](https://filamentphp.com/docs/5.x/components/form.md)
- [Infolist](https://filamentphp.com/docs/5.x/components/infolist.md)
- [Notifications](https://filamentphp.com/docs/5.x/components/notifications.md)
- [Schema](https://filamentphp.com/docs/5.x/components/schema.md)
- [Table](https://filamentphp.com/docs/5.x/components/table.md)
- [Widget](https://filamentphp.com/docs/5.x/components/widget.md)
